Install

With Terminal (recommended)

  1. Open Terminal: press ⌘ Space, type Terminal and press Return.
  2. Paste curl -fsSL https://unknown8575.github.io/DropDial-Releases/install.sh | bash and press Return.
  3. The installer picks the version for your Mac, checks the download’s fingerprint, puts DropDial in Applications and opens it. Run the same line again any time to reinstall.

Files fetched in Terminal aren’t marked as browser downloads, so macOS doesn’t ask. Gatekeeper stays on, and the installer only downloads from DropDial’s releases on GitHub. Read the installer.

From the downloaded .zip

  1. Open the downloaded .zip. DropDial appears next to it.
  2. Move DropDial to your Applications folder.
  3. Open DropDial. If macOS says it can’t check the app, open System Settings → Privacy & Security, scroll down and click Open Anyway.

DropDial isn’t notarized by Apple yet, so macOS asks once. After that it opens like any other app.

  1. Unzip the download: right-click it and choose Extract All…
  2. Run DropDial Setup.
  3. If SmartScreen says “Windows protected your PC”, click More info, then Run anyway.

The installer isn’t code-signed yet, so Windows asks once.

Updates

DropDial looks for a new version once a day. When there is one, a bar at the top of the window offers Update, and the new version installs when you click Restart to update or quit DropDial.

To look right away, click Check now in Settings → General. You can turn the daily check off there too.
